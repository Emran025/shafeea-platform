# المرحلة 2 — تحقيق الفهرسة

## 2.1 تقدير معدل الفهرسة الحالي

**تقدير عدد الصفحات المفهرَسة:** 0–3 صفحات  
**النسبة المئوية:** أقل من 5%  
**الثقة:** 90%

**الأدلة الداعمة:**

- `site:qayd.accsystemerp.com` لا يُعيد نتائج في البحث
- لا يوجد sitemap.xml
- SPA بدون SSR
- الدومين الفرعي بدون روابط خلفية تُوجّه الزاحف
- تحقق جوجل موجود (`public/ggl/google1ba3cc4c115ac1d9.html`) — وهذا يعني أن Search Console مُفعَّل، لكن لم تتم إضافة sitemap

## 2.3 مشاكل المحتوى المكرر

**الحالة:** منخفضة المخاطر حالياً  
**التفسير:** الموقع صغير بما يكفي لعدم وجود تكرار خطير.

**مخاطر محتملة مستقبلاً:**

- صفحات التوثيق قد تحتوي على مقاطع متكررة (الإدخالات المشتركة)
- URL parameters في الـ docs routing قد تُولّد نسخاً مكررة

---

## 2.4 الصفحات التي لن تُصنَّف

**صفحات بلا قيمة SEO يجب حجبها في robots.txt:**

```txt
/admin/*              — لوحة الإدارة (محمية بمصادقة)
/api/*                — نقاط API
/login                — صفحة تسجيل الدخول
/logout               — عملية تسجيل الخروج
/verify-email/*       — مسارات التحقق
/reset-password/*     — مسارات إعادة الضبط
```

---

## 2.5 ميزانية الزحف (Crawl Budget)

**التقدير الحالي:** الموقع لا يستفيد من crawl budget لأنه غير مُفهرَس أصلاً.

**بعد الإصلاح:** الموقع صغير (~70 صفحة)، لذا crawl budget ليس مشكلة فعلية. جوجل يزحف على مواقع من هذا الحجم بالكامل خلال ساعات.

---

## 2.6 خطة الفهرسة الكاملة

### الخطوة 1 — الفورية (أسبوع 1)

```txt
1. تصحيح HTML lang="ar" dir="rtl"
2. إنشاء sitemap.xml
3. تحديث robots.txt
4. إرسال sitemap عبر Google Search Console
5. طلب إعادة الفهرسة للصفحات الرئيسية
```

### الخطوة 2 — التقنية (أسبوع 2-4)

```txt
1. تطبيق SSR أو تحويل الصفحات التسويقية إلى Blade ثابتة
2. إضافة canonical tags
3. التأكد من أن روابط /docs/ هي anchor tags حقيقية
4. تحسين meta tags لكل صفحة
```

### الخطوة 3 — المراقبة (أسبوع 4+)

```txt
1. متابعة Google Search Console يومياً
2. رصد Coverage report
3. تتبع اكتشاف الصفحات الجديدة
```

**التوقع:** مع تطبيق هذه الخطوات، يُمكن الوصول إلى فهرسة 80%+ من الصفحات خلال 30-60 يوماً.
