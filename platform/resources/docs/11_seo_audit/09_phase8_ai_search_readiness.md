**الدرجة: 8/100**

## 8.3 تقييم إشارات E-E-A-T

**E-E-A-T = Experience + Expertise + Authoritativeness + Trustworthiness**

| الإشارة | الحالة | التقييم |
|---|---|---|
| **Experience** — تجربة حقيقية | الفلسفة والتوثيق يُظهران خبرة عميقة | متوسطة |
| **Expertise** — خبرة متخصصة | التوثيق التقني استثنائي (Ed25519، AES-256) | عالية في المحتوى الداخلي |
| **Authoritativeness** — سلطة خارجية | لا روابط خلفية، لا ذكر خارجي | ضعيفة جداً |
| **Trustworthiness** — الموثوقية | سياسة الخصوصية موجودة، شروط الاستخدام | متوسطة |

**نقاط القوة:**
- المحتوى التقني عميق ومُحكم (يُظهر Expertise حقيقية)
- فلسفة الشفافية والصدق مُوثَّقة جيداً
- أمان التطبيق مُشروح تقنياً

**نقاط الضعف:**
- لا اسم مؤلف أو كاتب محدد (E-E-A-T يُفضّل نسب المحتوى لأشخاص حقيقيين)
- لا صفحة "Team" أو "عن الفريق"
- لا شهادات مستخدمين
- لا ذكر في مصادر خارجية موثوقة

## 8.4 البنية الدلالية للمحتوى (Semantic Structure)

**التقييم:** متوسط-جيد للمحتوى الموجود، لكن لا يصل إلى Google

```
الهيكل الحالي:
✓ العناوين H1/H2/H3 في التوثيق (ملفات Markdown)
✓ محتوى نصي منظم ومتسق
✓ aria-label في بعض العناصر
✗ لا JSON-LD
✗ HTML dir="ltr" لموقع عربي (إشارة مربكة)
✗ محتوى الصفحات الرئيسية في DB (غير مُصيَّر بدون JS)
```

## 8.5 استراتيجية الظهور في البحث بالذكاء الاصطناعي

### الأسرع تأثيراً: المحتوى المُختار بعناية (Citable Content)

أنظمة الذكاء الاصطناعي تُفضّل المحتوى الذي:
1. يُجيب على سؤال محدد بشكل مباشر
2. يمكن الاستشهاد به (مُحكم ودقيق)
3. يظهر في مصادر متعددة

**التوصيات العملية:**
```
1. كتابة "تعريفات" قصيرة محكمة لكل مصطلح رئيسي
   مثال: "ما هو القيد المزدوج؟ — 3 فقرات بدون حشو"
   
2. إنشاء صفحة مقارنة شاملة بين قيد ومنافسيه
   (هذا النوع يُستشهد به كثيراً في Perplexity/ChatGPT)
   
3. نشر محتوى على GitHub README و Product Hunt
   (Perplexity يُفهرَس هذه المصادر بسرعة)
   
4. مشاركة في مناقشات Hacker News عن المحاسبة الشخصية
   والإشارة إلى قيد كحل للمشكلة المطروحة
```

## 8.7 خلاصة

قيد يمتلك **المحتوى الجوهري المطلوب** للبحث الذكاء الاصطناعي (توثيق عميق، مفاهيم واضحة، تقنية موثقة) — لكنه يُخفيه خلف:
- فهرسة شبه معدومة
- بنية SPA لا تُصيَّر بدون JavaScript
- غياب Schema
- انعدام الحضور الخارجي

**الهدف الواقعي خلال 12 شهراً:** رفع AI Visibility Score إلى 55-70/100 بتطبيق التوصيات التقنية + استراتيجية المحتوى.
